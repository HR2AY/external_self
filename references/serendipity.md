# Contemporary Serendipity Retrieval

## Purpose

Find a present-day, evidence-backed connection that becomes visible only when multiple personal nodes and current interests are considered together.

Unexpectedness matters, but it comes after truth. Do not manufacture coincidence.

## Select the context set

Use 2–5 relevant nodes. Include current-conversation entities such as a company, person, work, project, organization, subject, or place. Do not focus only on the last place mentioned.

Build a small intersection matrix:

- A ∩ B: two personal nodes.
- A ∩ C: an old node and a current interest.
- B ∩ C: another node and the current interest.
- A ∩ B ∩ C: only when a plausible bridge exists.

Potential bridge entities include organizations, schools, venues, neighborhoods, employers, collaborators, events, transit systems, publications, alumni networks, buildings, brands, projects, and public people.

## Hypothesis-first workflow

1. Form no more than three connection hypotheses before searching.
2. For each hypothesis, define what evidence would confirm it and what would disconfirm it.
3. Generate the smallest useful query set.
4. Search for the bridge entity, not merely each endpoint independently.
5. Verify dates and identity; namesakes and organizations with similar names are common failure modes.
6. Seek two independent sources for material person-organization or organization-event links when practical.
7. Stop weak paths early.

When a candidate connection is visually documentable, search for media that proves the bridge rather than merely illustrating either endpoint. Useful examples include an official event photo showing the named venue and organization, a dated project video, a contemporaneous poster naming both parties, or an archival image tied to the documented development.

Examples of worthwhile patterns:

- A place the user lived later became connected to a company or project they now follow.
- An old event shares a real organization, participant, venue, or publication with a current interest.
- A person or work now discussed has a documented connection to a former school, neighborhood, or institution.
- Two life stages intersect through a later public development the user is unlikely to have noticed.

Weak patterns include mere geographic proximity, matching words, broad industry similarity, shared nationality, or “both happened in the same decade.”

## Evidence and quality gate

Score a candidate connection:

| Dimension | Score |
|---|---:|
| Evidence quality | 0–3 |
| Connection strength | 0–3 |
| Personal relevance | 0–3 |
| Unexpectedness | 0–2 |
| Identity and date verification | 0–3 |

Normally present only results scoring at least 10, with at least 2 in evidence quality, connection strength, personal relevance, and identity/date verification.

If the bridge is plausible but not verified, label it **hypothesis** and usually keep it out of the main discovery. If nothing clears the threshold, say so.

Visual evidence follows the same threshold. Verify what the media depicts, its date, its original publisher/uploader, and how it supports the bridge. A logo, portrait, stock image, map screenshot, or generic city photo does not prove a connection. Do not display it as if it does.

## Output

Lead with the connection in plain language:

“我发现了一个你可能没想到的连接。”

Then give:

- The two or more personal/current anchors.
- The bridge entity or event.
- The evidence that confirms each side.
- The relevant dates, so the chronology is understandable.
- A clear boundary between fact and inference.
- A restrained explanation of why the connection is interesting.

If reliable bridge media exists, display it adjacent to the relevant connection with a short caption containing the media date, source/channel, and the exact side of the connection it confirms. Use an inline image or video player when supported; otherwise use a verified clickable thumbnail/preview with the video title. When presenting multiple substantial connections, seek a visual for each, while refusing weak or decorative substitutes.

Do not claim fate, destiny, hidden meaning, or causation when the evidence only supports association.
