# INFERENCE

This public package contains no personal inference data.

AI-derived relationships and hypotheses remain separate from FACT and BACKGROUND. Never migrate them into `places.json`.

```markdown

- Related nodes: node ID(s)
- Status: hypothesis | supported inference
- Evidence: source identities or citations

Reasoning, uncertainty, and disconfirming evidence.
```
